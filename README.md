# MohamedOsama Portfolio

A responsive, single-page student portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — design and responsive layouts
- `script.js` — mobile navigation and active section state

## Run on Windows
1. Extract this ZIP.
2. Open the folder.
3. Double-click `index.html` to view it in your browser.
4. Edit the files in Sublime Text or VS Code.

## Personalize before publishing
In `index.html`, replace:
- `your.email@example.com` with your real email
- GitHub and LinkedIn placeholder links with your profiles
- starter project descriptions with your real projects
- assignment cards with Google Drive links to your own files

## Publish
You can upload the folder to GitHub and import the repository into Vercel, or deploy it using another static hosting service. This is a static website and does not need a build step.
